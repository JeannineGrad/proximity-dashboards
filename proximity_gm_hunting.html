Central de vendedores · Visão geral
Vamos manter a estrutura do painel de vendas e agregar alguns elementos que vão reagir a eventos em tempo real:
  • Card de vendas Agora
  • Contador de envios de hoje (que vai somar as novas vendas)
  • Snack bar para notificar eventos em real time
  • Timer nas vendas que aparecem na lista
  • Botão para pausar a oferta de vendas instantâneas
Vista rows de ventas
Para as vendas listadas no painel vamos adicionar um contador de tempo para cada venda.

Também vamos ajustar os titulos para refletir os novos estados (especialmente relacionados às interações com entregadores).

Snackbar
Vamos mandar um snackbar de atualização para que o seller possa ver as mudanças refletidas nos cards de vendas. As atualizações que vamos notificar são:
  • Nova venda
  • Venda cancelada
  • Entregador chegou para retirada
  • Entregador saiu para entrega
Será necessário clicar em “Atualizar” para ver as novidades refletidas nos cards de venda.
